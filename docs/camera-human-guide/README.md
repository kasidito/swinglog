# ภาพคนช่วยจัดเฟรมกล้อง

เปิด **วิดีโอ → เปิดกล้องพร้อมกรอบจัดตำแหน่ง** จะเห็นภาพคนโปร่งใสยืนจรดลูกพร้อมไม้กอล์ฟแทนการใช้กล่องตัวคนเพียงอย่างเดียว มีภาพคนสองมุมแยกกัน: ด้านหลังตามแนวตี เห็นหลัง/ด้านข้าง และด้านหน้า เห็นเท้าสองข้างชัดเจน ภาพใช้ผู้สาธิตสมมติชุดเดียวกัน เป็นภาพ AI ไม่ใช่คนที่ติดตามได้จากกล้องสดหรือโมเดล 3D

- ขยับตำแหน่งกล้อง/ระยะถ่ายให้ตัวจริงมีขนาดใกล้ภาพตัวอย่าง โดยยังเห็นเท้าและไม้ตอน top ครบ ไม่ต้องบังคับร่างกายให้ทาบทุกส่วน ภาพเป็นตัวช่วยกะเฟรม ไม่ใช่เกณฑ์มุมข้อต่อหรือการตรวจท่าถูกผิด
- ตัวอย่างใช้เหล็กกลาง ตำแหน่งลูกและท่าจริงต้องปรับตามไม้และสัดส่วนของผู้ตี คำอธิบายอยู่ใน “วิธีตั้ง”
- ภาพเริ่มที่ความชัด 55% ปรับได้ 20–80% หรือกด “ซ่อนภาพคน” เพื่อใช้ไกด์เส้น มือ/ลูก/เท้าไม่ย้ายเมื่อซ่อนภาพ
- รองรับมือซ้ายด้วยการกลับด้านเฉพาะภาพและพิกัดกำกับ ข้อความไทยอ่านตามปกติ ภาพยังคงสัดส่วนเมื่อใช้ “ภาพเต็มจากกล้อง” ทั้งแนวนอนและแนวตั้ง
- ไกด์อยู่ใน DOM ของพรีวิวเท่านั้น ตัวบันทึกยังอ่านจาก video source เดิม ไม่มีรูปคน ข้อความ หรือไกด์ฝังในวิดีโอ และไม่ใช้ภาพ AI ในการคำนวณท่าหรือผลตี
- ภาพ WebP โปร่งใสสองไฟล์รวมประมาณ 183 KiB เก็บในโปรเจกต์และ PWA precache ไม่ใช้บริการภายนอกขณะเปิดกล้อง หากโหลดไม่ได้จะขึ้นข้อความและไกด์เส้น กล้องกับการนำเข้าคลิปยังใช้ได้

ไม่มีการเพิ่ม dependency, backend หรือเปลี่ยนประวัติ/รูปแบบข้อมูลซ้อม ดู [media-manifest.json](media-manifest.json) สำหรับ prompt จริง ไฟล์ต้นฉบับ แหล่งอ้างอิง และสถานะการตรวจ

## การตรวจ

รัน `npm test`, `npm run build`, `npm run build:single` แล้วเสิร์ฟ `dist/` ที่ localhost:5181 ตาม [วิธีทดสอบกล้องเดิม](../camera-demo/verification.md)

```sh
python e2e/make_camera_fixtures.py
python e2e/make_analysis_fixtures.py
python e2e/camera_human_guide.py
python e2e/camera_demo.py
```

สคริปต์ใหม่ตรวจสองมุม ภาพมือซ้าย ความชัด/ซ่อนภาพ สัดส่วนใน native landscape และภาพที่ถอดรหัสจากการอัดว่ามีเพียงสีจากกล้อง ไม่มีคนตัวอย่างติดไป รวม 24 ชุดขนาด/ธีม/ตัวอักษร/มือ ทั้งสองมุม พร้อมโหลดภาพออฟไลน์และกรณีภาพหาย

การตรวจภาพและการจับกริปเป็นการดูโดย agent เท่านั้น **ยังไม่มีโปรกอล์ฟตรวจ ไม่มีการทดสอบกับผู้เริ่มเล่นจริง และไม่มี iPhone/Safari จริงเชื่อมต่อให้ทดสอบ** Chromium กับกล้องสีสังเคราะห์ยืนยันพฤติกรรมซอฟต์แวร์ ไม่ยืนยันความถูกต้องทางชีวกลศาสตร์หรือความเข้ากันได้ของ iPhone
